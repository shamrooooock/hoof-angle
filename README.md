# 蹄冠角度ノート
シャムロック乗馬クラブ向けの静的MVP。依存ライブラリ・外部API・ビルド不要。写真はメモリ内で処理し、サーバーへ送信・永続保存しません。原本は変更しません。

## 使い方
写真を選択（または撮影）→ 前方A → 後方Bをタップ → 点をドラッグして微調整 → 測定画像を保存。
拡大縮小はピンチ／ホイール／＋−。点以外のドラッグでパン。全体表示で復帰。
A/Bボタンで対象点を選択して置き直せます。矢印キーは1画像画素、Shift併用は10画素移動。
画像形式はブラウザがデコードできるもの。HEICなど読み込めない画像はJPEG/PNGへ変換してください。

## GitHub Pagesで公開
このフォルダーの中身をGitHubリポジトリのルートへアップロードします。
Settings → Pages → Deploy from a branch → main / (root) → Save。
発行されたHTTPS URLを開いてください。サブパス配置にも対応しています。
公開URL: https://shamrooooock.github.io/hoof-angle/
ローカル確認は node server.mjs （要Node.js）。http://127.0.0.1:4173 を開きます。
file:// で直接開くとES ModulesとService Workerが動かないため、HTTPサーバーが必要です。

## PWA
準備完了の表示はService Workerのインストール完了後です。初回は通信必須。iOSはSafari共有からホーム画面へ追加、Androidはブラウザメニューから追加します。
キャッシュはアプリファイルのみ。写真は再起動すると消えるため、必要な結果はPNG保存してください。OSによるサイトデータ削除後は再度オンラインで開く必要があります。
リリース時は sw.js のCACHE名を更新。開いているタブは再読込してください。

## 計算・座標
デコード後のEXIF向き補正済み元画像座標を保存。表示変換を逆変換して点を指定し、表示倍率・画面サイズから独立して計算します。
蹄冠角度 = atan2(abs(A.y − B.y), abs(B.x − A.x)) × 180 / π。
蹄冠角度は水平に対する傾きの大きさ（0〜90°）です。左右・上下の向きによらず非負の値になり、推定値もこの角度から計算します。画像のy座標は下向き。
推定値 = 30 − 蹄冠角度。未丸め値から計算して、小数第1位で表示。1画像画素未満の点間距離は無効。
createImageBitmap(imageOrientation: from-image)でEXIF方向を適用し、非対応時はブラウザ標準Imageデコードを使用。回転・水平補正は行いません。
保存PNGは長辺最大2400px、元画像全体と基準点・線・結果・座標・保存日時を記載します。

## モデルの扱い
依頼仕様に基づき、WEPAでStefan Wehrli氏から紹介されたとされる30°モデルを暫定式として実装しています。モデルの医学的検証や出典確認は実施していません。X線実測と同じ精度を保証せず、診断用途ではありません。

## 構成・検証
app.js: 読込・Pointer Events・描画・保存、geometry.mjs: 純粋な座標・角度計算、style.css: レスポンシブUI、sw.js: オフライン。
node --test geometry.test.mjs で角度、左右向き、近接点、座標変換の回帰テスト。
